# 界面体验与 Arco Design 规范

## 当前标准

平台统一使用 Arco Design Vue 作为主要 UI 组件库。页面设计以企业内部工作台为目标，强调清晰、紧凑、稳定和可重复操作。

## 当前实现

- 已安装 `@arco-design/web-vue@2.58.0`，并从 `delivery-platform-web/src/main.ts` 引入。
- 全部运行页面使用原生 Arco Design Vue；旧 `arco-compat/`、旧图标别名、`@ts-nocheck` 兼容文件和退出运行时的页面样式已删除。
- `components/business/` 统一页面容器、工具栏、卡片、表格、抽屉、弹窗、状态、表单、空态、错误态和权限态。
- 页面模式、组件复用和完整路由见 [前端页面架构](frontend-architecture.md)，正式约束见 [前端实施规范](frontend-architecture-refactored.md)。

## 组件维护优先级

维护页面时，优先复用和检查以下组件：

- 按钮
- 表单
- 输入框
- 选择框
- 表格
- 弹窗
- 抽屉
- 容器内无限滚动
- 消息提示
- 通知提醒

## 验收要求

- `pnpm --dir delivery-platform-web build` 通过。
- 关键页面没有明显视觉回退。
- 表单校验、滚动续载、弹窗确认和错误反馈正常。
- 加载、空数据、错误、禁用、只读、无权限和校验失败状态都经过检查。
- 不新增其他 UI 组件库。
- 中文与英文固定文案 key 集合一致，核心页面模板不保留硬编码中文。
- 浅色、深色和跟随系统模式都需检查；移动端重点保证查看、搜索、上传、审核和简单操作。

## 布局规则

- 业务页面保持紧凑、偏工作台风格。
- 应用侧栏展开态固定 `180px`、收起态固定 `48px`，图标固定 `18px`；桌面浏览器、飞书 WebView 和 iframe 均不得因可视区域变化压缩图标、文字或菜单行。
- 主内容区只吸收侧栏之外的剩余宽度；窄桌面嵌入窗口保持固定侧栏，侧栏抽屉仅用于 `600px` 以下的粗指针触控设备。
- 筛选项尽量少，并优先保持在一行。
- 避免卡片套卡片和过大的装饰区域。
- 列表较长时优先在内部框架滚动，避免外层页面滚动导致界面不稳定。
- 项目概览采用 Arco Pro 紧凑工作台布局：13px 页面内边距、12px 纵向模块间距、2px 控件圆角、`#E5E6EB` 弱边框和 `#F2F3F5` 表头背景。
- 项目概览使用单一 100px 横向五指标带，48px 透明图标容器内放置 Figma 导出的 28px 线性图标，不增加图标底色或指标分隔线；搜索框、查询、刷新和新建均为 32px 高度。
- 项目概览表格使用白色/`#F7F8FA` 斑马纹，行悬停使用浅蓝高亮，项目名称首列固定并带右侧阴影；项目档案目录和文件表按 Figma 固定为 44px 行高。
- 项目概览字体使用 Noto Sans SC、苹方和微软雅黑回退链，数字使用等宽数字特性，按钮、输入框、选择器和标签统一保持 2px 圆角。
- 项目档案使用 100px 五指标带、32px 单行工具栏和 270/937px 连续工作区；不增加 Figma 节点中不存在的筛选、分页、卡片或响应式重排。
- 全部业务列表默认显示或请求 20 条，在列表容器接近底部时自动载入下一批；达到总数或返回不足 20 条时停止，不显示分页器。
- 表格列总宽度小于可用宽度时，各列均匀撑满容器；总宽度超过可用宽度时由唯一的表格视口承载横向滚动，单元格保持单行，固定名称列不随横向滚动移动。
- 标准库和知识库分别严格匹配 Figma `70:322`、`125:624`，使用语义表格网格。标准库右侧最小 937px，1440×900 基线五列为 `365/90/130/170/182px`，宽屏由标题列吸收剩余空间；表头与数据行均为 44px，左右工作区自适应撑满剩余高度并分别内部滚动，不显示分页器。知识库继续按自身 Figma 节点维持 937px 网格和 72px 分类说明，标准库分类说明为 80px。项目档案文件表总宽 937px，六列严格保持 `340/80/100/113/122/182px`，目录与表体分别纵向滚动。
- 项目详情使用 944px 居中弹窗和半透明遮罩，弹窗最高 85vh；顶栏在同一行展示标题、权限动作和关闭按钮，正文使用 24px 水平边距并独立滚动。
- 项目详情不使用卡片嵌套，基本信息采用三列，阶段合同与团队采用四列，风险档案采用三列；分区之间只使用弱分隔线。
- 知识库和文档模板的文件标题预览交互保持一致。
