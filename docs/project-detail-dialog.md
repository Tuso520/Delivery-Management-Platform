# 项目详情弹窗

项目概览中的新建、编辑和查看统一使用 `ProjectDetailDialog`。三种模式共用字段顺序、款项计划、数据查询和关闭行为，路由仅负责传入模式与项目 ID，不再维护独立抽屉或详情页。

## 交互与布局

- 设计基准：Figma `59:1662`，桌面端弹窗宽 944px、高 608px，标题栏高 48px。
- 标题栏固定显示“项目详情”；正文独立滚动，桌面端基础信息采用四列工作台式布局。
- 新建和编辑态显示保存按钮；查看态禁用所有表单控件，并隐藏保存、添加、编辑和删除操作。
- 表单存在未保存修改时，关闭按钮、遮罩和 Esc 均先显示放弃修改确认。
- 保存期间禁止重复提交；项目详情、款项计划、项目列表和概览统计在成功后同步刷新。
- 归档模板允许回显项目当前使用的历史模板，但新选择仍来自有效模板集合。

## 数据与权限

- 项目和款项计划在同一个后端事务中创建或更新；被移除的款项计划执行软删除。
- 款项计划 ID 必须属于当前项目；合同金额与款项金额合计必须完全一致，币种必须与项目合同币种一致。
- 金额通过十进制字符串传输和计算，前端不使用 JavaScript 浮点数求和；服务端使用 Prisma Decimal，支持最多 16 位整数和 2 位小数。
- 后端执行最终的项目、合同、财务、验收、进度和款项权限校验。无款项操作权限时，项目更新不会隐式覆盖现有款项计划。
- 项目经理、电气工程师和软件工程师必须符合相应人员角色；清空负责人时同步移除对应项目成员关系。
- 签约、启动和预计验收日期按业务顺序校验，项目进度限制为 0 至 100。

## 验收范围

- 单元与契约测试覆盖金额格式和精确比例、路由模式复用、后端事务、权限、外部款项 ID、金额合计和软删除。
- Playwright 连接真实 NestJS、MySQL、Redis 和 MinIO 栈，覆盖创建、编辑、款项增删、超大 VND 金额持久化、查看态只读、脏数据确认以及 1024px 视口。
